本次发布包含自 0.5.1 以来的迭代，以及白金头部、临光腿部遮挡修复。
This release includes the iterations since 0.5.1 and the latest Platinum/Nearl layering fixes.

- 实体与玩家动画槽、GIF/MP4/WebM 导入、角色动作文件夹匹配、自定义背景。
  Entity/player animation slots, GIF/MP4/WebM import, action-folder matching and custom backgrounds.
- 游戏内 PRTS 资源抓取，逐文件进度、成功/部分失败/失败/取消反馈。
  Native PRTS downloader with per-file progress and success/partial/failure/cancellation results.
- 全量外观包：复制、保存、整体读取、导入/导出；内置默认、i能tv、白金·临光。
  Complete appearance packages: copy, save, replace, import/export; Default, i能tv and 白金·临光 presets included.
- 白金头部位于身体与四肢之后；临光身体与裙摆遮住腿部。旧示例自动修正，保留其他自定义配置。
  Platinum's head draws behind the torso/limbs; Nearl's torso/skirt cover the legs. Original older examples are repaired while preserving other custom settings.
- 缩短蹬墙动画、R 自杀、完整/断肢布娃娃、电击与红色喷溅；恢复 0.5.1 操作参数。
  Shorter wall-jump pose, suicide input, intact/detached ragdolls, electric and red splash effects; 0.5.1 movement settings retained.
- 区分激光与机枪无人机；激光固定瞄准方向，0.75 秒预警、2 秒光束、1 秒冷却。
  Distinct laser/chaingun visuals; locked laser aim, 0.75-second warning, 2-second beam and 1-second cooldown.
- 中英双语使用说明，包含在下载包中。
  Chinese/English instructions included in the download.

下载 `NVLink-v0.6.1-Windows.zip`，解压后运行 `Play.cmd`。请保留 `tools/ffmpeg.exe` 与许可文件。升级时保留旧 `userdata/` 可继续使用设置与预设。

Download `NVLink-v0.6.1-Windows.zip`, extract it and run `Play.cmd`. Keep `tools/ffmpeg.exe` and license files. Preserve the previous `userdata/` folder to retain settings and presets.

PRTS 抓取的是 Spine 原始文件，不会一键生成任意角色的可播放动画；游戏动作导入使用 GIF/MP4/WebM。当前仍为原型，地图编辑器和回放尚未实现。

PRTS downloads raw Spine files, without universal conversion into playable animation; import gameplay clips as GIF/MP4/WebM. This remains a prototype; map editing and replay playback are not implemented.

验证：既有模拟/UI/动作/资源测试通过；最新版 51 项预设/迁移/抓取检查与 35 项媒体检查通过。便携版启动、预设加载、真实 HTTPS 抓取及左右跑动图形检查通过。

Validation: existing simulation/UI/animation/resource checks passed; the latest 51 preset/migration/downloader and 35 media checks passed. Portable startup, preset loading, live HTTPS download and both-facing run visuals were verified.
